# Skill Library

Curated collection of reusable AI agent skills for the Hermes/ECC ecosystem.

## Structure

```
skill-library/
└── 2026-10-03/
    ├── README.md
    ├── references/     # Reference implementations
    └── sources/        # Source skill definitions
```

## Usage

Skills are designed for use with:
- **Hermes Agent** — desktop AI assistant
- **ECC (Everything Claude Code)** — autonomous coding harness
- **OpenClaw** — agent orchestration platform

## Adding Skills

1. Place skill in `sources/<skill-name>/SKILL.md`
2. Add any references in `references/`
3. Update this README with skill description
